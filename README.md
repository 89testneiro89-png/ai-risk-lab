# AI Risk Lab

Интерактивная учебная песочница для курса **«Специалист по информационным системам: оптимизация процессов создания цифровых решений»**.

## Раздел 6.3

Стенд используется для двух практических занятий:

- **6.3.1 — анализ и оценка рисков применения генеративного ИИ**
- **6.3.2 — разработка мероприятий по снижению рисков**

## Что умеет стенд

- 3 интерактивных кейса;
- намеренно заложенные ошибки и рискованные сценарии;
- скрытый разбор после самостоятельной работы студента;
- рабочий реестр рисков;
- поля для вероятности, основания, мероприятий и проверки;
- сохранение данных в браузере;
- экспорт результата в CSV.

## Кейсы

1. **ИИ-помощник обработки обращений** — неподтверждённые факты.
2. **Корпоративный ИИ** — передача данных во внешний сервис.
3. **ИИ-консультант по базе знаний** — ответы вне базы и противоречие источнику.

## Безопасность учебной практики

Все данные синтетические. Сайт не подключён к реальному API нейросети и не отправляет введённые данные на сервер.
